# Twelve-prompt research programme
One prompt per user authorization. After each: append evidence and bibliography, update novelty matrix and progress, commit and verify GitHub files, then STOP and request permission for the next prompt.

01. Initialize repository and verified baseline.
02. Classical optimization, extended formulations, column generation, network design, structural transformations.
03. Canine olfaction, infotaxis, multimodal sensing and plume tracking.
04. Bayesian experimental design, POMDP, active sensing, value of information.
05. Adaptive submodularity, sequential probing, identification and information lower bounds.
06. Network augmentation/repair, bilevel design, endogenous uncertainty and constraints.
07. Proof certificates, proof logging, formal verification and certificate complexity.
08. 2023–2026 literature update plus citation-chaining and competing methods.
09. Verify/deduplicate references, synthesize evidence, identify unresolved overlaps; evidence freeze gate.
10. Formal definitions, models, conjectures and minimal counterexamples.
11. Adversarial proofs, lower bounds, novelty testing and theorem gate.
12. Manuscript master blueprint, claim-to-reference map, experiment design and approval gate.

Only after author approval: software -> tests -> experimental artifacts -> manuscript. Never invent citations, proofs, results or GitHub commits.
