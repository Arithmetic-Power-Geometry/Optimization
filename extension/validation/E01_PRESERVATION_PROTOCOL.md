# E01 — Preservation and research execution protocol

1. **Write boundary:** All new files and modifications for extension E01–E22 stay in extension/. The completed prompts/, evidence/, theory/ and manuscript/ paths remain untouched.
2. **Source preservation:** Preserve all existing sections and original prose; additions only as related subsections/subsubsections within existing numbered sections. Never fabricate a missing TeX source from summaries. Freeze exact source bytes, checksums, provenance before manuscript integration.
3. **Evidence vocabulary:** PLANNED = proposed, EXECUTED = actual tool/process run, VERIFIED = independently checked raw artifact or proof, BLOCKED = missing prerequisites. Never equate GitHub commit with simulation, theoretical proof or journal acceptance.
4. **Model integrity:** Distinguish physically accessible path tests from edge-local oracles; route availability from probe outcome; encoded witness from physical truth; robust worst-case from expected loss; one irrevocable repair from reversible edits. Maintain matched budgets, horizons, priors, feasible actions and cost accounting.
5. **Scientific originality:** Preserve prior 20-stage NO-GO. Directly test reductions to overlapping decision regions, tomography, POMDP and DDID. Publish negative findings and limitations.
6. **Software and data:** For executable stages, save dependencies, random seeds, exact configurations, test assertions, raw logs, dataset provenance, checksums and reproduction commands. Mark missing Mininet/ns-3 tooling BLOCKED, never EXECUTED.
7. **Figures/tables:** Derive all quantitative paper tables/figures from checked source artifacts, cite in manuscript, use [H] placement, audit labels and references. Protocol tables are not empirical results.
8. **Stage gate:** Update extension/PROGRESS.md, commit stage artifacts, independently re-fetch every changed path with SHA and content check, report GO/NO-GO and stop before the next stage until explicit author authorization.
9. **Readiness:** 100/100 is an aspirational rubric only. No guaranteed novelty, Q1 status, software results, or journal acceptance.
